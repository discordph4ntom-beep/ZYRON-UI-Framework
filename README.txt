ZYRON UI FRAMEWORK

Architecture Lua modulaire pour Roblox Studio.

Installation :
1. Ouvre Roblox Studio.
2. Crée un dossier ZYRON dans ReplicatedStorage.
3. Reproduis les dossiers core, interface et modules.
4. Transforme les fichiers Lua en ModuleScripts.
5. Place main.lua dans un LocalScript.
6. Adapte les chemins require() à la hiérarchie Roblox.

Le module Visuals est une base de démonstration.
